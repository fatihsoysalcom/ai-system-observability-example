# AI System Observability Example

This example demonstrates the difference between traditional monitoring and observability in a simplified AI-like system. While traditional monitoring only shows the final outcome (e.g., loan approved/rejected), observability provides deeper insights into the system's internal state and decision-making process, explaining *why* a particular outcome occurred. This helps in diagnosing unexpected behavior and understanding model decisions.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal using `python main.py`.
